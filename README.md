# Clínica Odonto

Sistema de gestão para clínica odontológica: pacientes e anamnese, agenda, prontuário com auditoria
e odontograma (FDI).

> Projeto de portfólio. **Todos os dados são fictícios.**

## Estrutura

```
backend/    API Java 21 + Spring Boot 3 (monólito modular)
frontend/   React + TypeScript (etapa futura)
docs/adr/   decisões de arquitetura
```
